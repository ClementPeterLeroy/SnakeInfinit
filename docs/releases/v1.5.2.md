# v1.5.2 — Spatial Intelligence Foundations

Frontier Training now supports four CPU DQN configurations: the original
355-parameter 11-input MLP, a 3,459-parameter distance19 MLP, and two
188,419-parameter spatial CNNs using binary or ordered-body observations.

Open **AI → Training Center → Frontier Training**. With **SOURCE: new**, click the
model configuration selector to cycle A/B/C/D, choose budget and seed, then start.
The screen displays the architecture, encoder, input shape and parameter count.
B hidden-layer widths are configurable in **Advanced DQN**; C/D share fixed layers.
Existing model and checkpoint sources restore their saved architecture/encoder.

All four configurations use the existing replay-based learning equations, target
network, rewards and default hyperparameters. They support milestone/final model
exports, boundary recovery, frozen Arena playback, seeded evaluation and existing
Analysis charts/comparisons/CSV controls. The Neural Laboratory retains its original
11-input neuron inspection and editing workflow.

New artifacts explicitly identify their architecture and observation encoder.
Historical format-1 models remain readable without edits. Share both the `.pt`
and matching `.json` from `experiments/frontier/<experiment-id>/models/`.
**OPEN EXPERIMENT FILES** opens the visible run directory. No historical experiments
or protected baseline model files are rewritten.

The full suite passes **400 tests**. Short pilots completed 9,984 B steps and 6,912
C/D steps each before their configured pause, with successful optimization,
checkpoint recovery, portable model reload, Arena evaluation and Analysis export.
CNN pilots reached the two-minute cap; no full research training run was performed.
Measured training throughput was approximately 692 B steps/s and 57 C/D steps/s
on this CPU. Short paired A checks preserved exact transitions/weights with a
median throughput difference of about −0.6%. These are engineering measurements,
not model-quality comparisons.

See [exact architecture and checkpoint conventions](../spatial-architecture.md),
[research methodology and roadmap](../ai-research.md), and
[tests, changed files, timings and limitations](../spatial-validation.md).

research remain later roadmap items.
