# v1.3.0 — Neural Foundations

Adds a functional AI → Neural Laboratory while retaining the established
Classic, Arcade, five challenge modes, branding, startup video, audio and records.
Training remains a v1.4 placeholder.

- Optional CPU PyTorch loads only when the laboratory opens, with a responsive
  loading screen and graceful missing/broken-dependency message.
- Pure 11-feature Classic observation encoder and three relative actions.
- Configurable 1–5 hidden layers, 2–128 units each, four activation functions,
  seeded initialization and actual parameter count (default 355).
- Bounded network graph, individual neuron calculations, scrollable inputs,
  validated manual parameter edits, binary input editor and forward comparisons.
- Separate seeded Classic environment and single-step manual/UNTRAINED actions.
- Step and Live operating modes, adjustable 1/3/5/10/20-step-per-second continuous
  untrained control, Play/Pause/Stop/Reset and explicit game-over replay controls.
- Real-time activation visualization, highlighted raw-output argmax, and immutable
  pre-action decision inspection alongside the explicitly post-action board.
- FPS-independent bounded scheduling, retained catch-up work, reported excessive
  backlog cancellation, responsive resize/events, and cached connection artwork.
- Staged supervised MSE/Adam demonstration with actual gradient inspection.
- Trusted-local-model library: validated JSON configuration and weights-only
  tensor files, checksums, atomic metadata replacement and overwrite confirmation.
- Version and Windows metadata updated; lightweight build still excludes Torch.

## Manual verification

1. Install `requirements-ai.txt` in the runtime interpreter and run `main.py`.
   Open AI → Neural Laboratory. Check the default 355-parameter model.
2. Configuration: change sizes/activation/seed, Build, cancel once, then confirm.
   Try an invalid size. Rebuild twice with the same seed to reproduce weights.
3. Laboratory: reset using seed 1234, Step, Forward, select/apply relative actions,
   and try Network Action. Step Mode makes at most one movement per click;
   Forward makes none. Switch to Live Mode, Play, cycle speeds and resize the window.
   Pause: confirm the board, outputs, selected neuron and decision remain unchanged.
   Inspect the PRE-ACTION snapshot and compare with the POST-ACTION board. Use
   Current State / Forward, then Inspect Last Decision to compare both moments.
   Stop to return to Step Mode without resetting. After death, check score, steps,
   cause, Reset & Play Again, and Return to Step Mode. No automatic restart occurs.
4. Toggle an input and compare output changes. Restore the real Snake inputs.
   Click neurons; select exact indices; click a weight or Bias and edit a value.
   Build 128-unit layers and scroll to the last incoming weight.
5. Gradient Demo: enter targets, Backpropagate, inspect gradients, then Optimizer
   Step. Check actual loss and output changes. Repeat only by explicitly clicking.
6. Models: save, try saving the same name and cancel/confirm overwrite. Edit the
   model, load the saved one after confirming trust/replacement, and compare values.
7. Return to SOLO and play every mode. Run from an arcade-only environment to
   confirm all seven modes work and the AI menu explains the missing dependency.

## Limits

This is an educational untrained network, not a Snake-playing intelligence. Manual
inputs may be inconsistent with a board. The encoder covers Classic only. No DQN,
automatic episode restarts, replay buffers, PyTorch GPU mode, or automated training is
implemented. Supervised targets are not optimal Snake actions. A single optimizer
step is not guaranteed to improve arbitrary targets. Last-backward gradients are
snapshots after an optimizer update. Large graph nodes are labeled groups with
representative connections; numerical inspection remains exact.

Save files include model/configuration and metadata, not the environment or Adam
state. Load only trusted files. Seed reproducibility is intended for the same
runtime/device; exact cross-version Torch results are not promised.

Run from source for AI. Existing v1.2.1 binaries have not been rebuilt, and the
lightweight build deliberately excludes Torch. No new AI-enabled executable or
clean-machine distribution test is claimed. Dummy/offscreen rendering tests do
not prove audible playback or a complete human usability session.

The next milestone is **v1.4 — First Intelligence**, introducing Deep Q-Learning.
No Git staging, commits, pushes, tags, releases, or publishing are part of this update.
